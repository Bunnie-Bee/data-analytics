## Introduction

This repository documents my systematic progression from a linguistics background into the field of data analytics and ultimately towards a career as a data scientist. The goal is to build a solid foundation across the full analytics stack—spreadsheets, programming, data visualization, database technologies, statistical modeling, and machine‑learning—while reflecting on each learning milestone, sharing code, visual artifacts, and insights.

---

## Learning Roadmap

The journey is organized into three primary tracks, each represented by a dedicated sub‑directory:

1. **Excel** – Fundamentals of data manipulation, cleaning, and exploratory analysis using Microsoft Excel. Topics include:
   - Navigation, formulas, and functions (`SUM`, `AVERAGE`, `VLOOKUP`, `XLOOKUP`)
   - Data cleaning techniques (handling missing values, removing duplicates, standardising formats)
   - Pivot tables, charts, and dashboard creation
   - Advanced tools such as Power Query and Power Pivot

2. **Python** – Core programming skills for data science. Topics include:
   - Python syntax, data structures, and control flow
   - NumPy for numerical computation
   - Pandas for data wrangling and transformation
   - Data visualization with Matplotlib, Seaborn, and Plotly
   - Introduction to statistical analysis (hypothesis testing, confidence intervals)
   - Foundations of machine learning with scikit‑learn (regression, classification, clustering)
   - Development of reproducible notebooks and modular scripts

3. **Power BI** – End‑to‑end business intelligence workflow. Topics include:
   - Data ingestion and transformation with Power Query
   - Data modeling using relationships and DAX measures
   - Designing interactive reports and dashboards
   - Publishing to the Power BI Service, workspace management, and collaboration
   - Advanced features such as Row‑Level Security, AI visualisations, and paginated reports

### Complementary Skills and Technologies

Beyond the three main tracks, I will also develop proficiency in the following areas, linking the analytical workflow together:

- **SQL and BigQuery** – Structured query language for relational data, cloud‑based analytics, and BigQuery‑specific optimizations.
- **Statistical Foundations** – Descriptive statistics, probability theory, inferential methods, and experimental design.
- **Machine Learning Theory** – Supervised vs. unsupervised learning, model evaluation, hyper‑parameter tuning, and model deployment concepts.
- **Version Control & Collaboration** – Git workflows, pull‑request etiquette, and documentation best practices.
- **Data Engineering Basics** – Understanding of ETL pipelines, data lake concepts, and cloud data services (Google Cloud Storage, Dataform, dbt).
- **Cloud Platforms** – Exposure to Google Cloud Platform services relevant to data science, such as BigQuery, Cloud Storage, and Vertex AI.

## Goals

1. **Technical Mastery** – Acquire hands‑on competence in each technology, demonstrated through completed projects, notebooks, and dashboards.
2. **Portfolio Development** – Build a publicly accessible portfolio of analytical artifacts (Excel workbooks, Python notebooks, Power BI reports) that showcase end‑to‑end problem solving.
3. **Certification & Credentialing** – Pursue relevant certifications (e.g., Google Data Analytics Professional Certificate, Microsoft Power BI certification) to validate skills.
4. **Community Engagement** – Share insights via blog posts, open‑source contributions, and participation in data‑science meetups.
5. **Transition to Data Scientist** – By the end of the roadmap, be capable of designing and executing complete data‑science projects: problem formulation, data acquisition, exploratory analysis, feature engineering, model building, validation, and deployment.
