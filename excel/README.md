## Introduction

Welcome to my **Excel Learning Journey**. Coming from a linguistics background, I embarked on the path of data analytics starting with Microsoft Excel – a powerful tool that transforms raw numbers into compelling stories.

---

## My Learning Path

### 1. Getting Started with Excel
- Familiarised myself with the Excel interface, worksheets, and basic navigation.
- Learned fundamental concepts such as **cells**, **rows**, **columns**, and **workbooks**.
- Explored essential functions like `SUM`, `AVERAGE`, `COUNT`, and simple **conditional formatting** to highlight key insights.

### 2. Data Cleaning Foundations
- **Missing Values** – identified blanks and used techniques like *filtering*, *Find & Replace*, and the `IFERROR`/`IFNA` functions to handle them.
- **Duplicate Removal** – leveraged *Remove Duplicates* and the `COUNTIF` function to detect and clean duplicate records.
- **Inconsistent Data** – applied *Data Validation* and *Text Functions* (`TRIM`, `PROPER`, `UPPER`, `LOWER`) to enforce consistency.
- **Error & Outlier Detection** – used *Conditional Formatting* and *Statistical Functions* (`STDEV.P`, `MEDIAN`) to spot anomalies.
- **Standardising Columns** – created **standardised column headers**, converted data types, and aligned date formats using `TEXT`, `DATE`, and *Power Query*.
- **Working with Dates** – parsed, formatted, and performed calculations on dates (e.g., `DATEDIF`, `EOMONTH`).

### 3. Advanced Excel Features
- **Pivot Tables & Charts** – summarised large datasets, performed multi‑dimensional analysis, and visualised trends.
- **Lookup Functions** – utilised `VLOOKUP`, `HLOOKUP`, `INDEX` + `MATCH`, and the newer `XLOOKUP` for relational data tasks.
- **Data Modelling** – introduced *Power Query* for ETL‑style transformations and *Power Pivot* for creating data models.

---

## Excel Capstone Project

My final project combined everything I learned:
- Imported a raw dataset containing sales records.
- Cleaned the data using the techniques above (missing‑value handling, duplicate removal, outlier correction).
- Built a dashboard with **Pivot Tables**, **Slicers**, and **Dynamic Charts** to answer business questions such as:
  - *Which product categories performed best each quarter?*
  - *How did regional sales trends evolve over time?*
- Documented the analytical process, showcasing how clean data drives meaningful insights.
